True Digivice

Introduction​

The True Digivice is a progression-based Digivice that provides unique visual effects for your Tamer along with two customizable Attribute options.

The base Digivice of Beginning Lv.0 is obtained by completing the main quest in Minato City. It can then be upgraded through several stages until reaching the final True Digivice.

All upgrades are crafted through Nanomon (Item Craft) at DATS Center using materials dropped from various Tokyo-Odaiba raid bosses.

Digivice Attributes​

Option System​

  • Every True Digivice has 2 customizable options.
  • Options can be rerolled using Option Change Stone and Number Change Stone.
  • Options can be enhanced up to 200% with Digitary Power Stone.
  • Options can also be renewed using Renewal Increase Stone.
  • Duplicate options cannot appear on the same Digivice.

Unlike Ring, Necklace, Earring, and Bracelet Attributes, Digivice Attributes increase the Skill Damage of Digimon with the selected Attribute, not damage against Attribute advantage.

For example, Light Attribute increases the skill damage of every Light Digimon regardless of the enemy's Attribute.

Resetting True Digivice​

Since the resulting True Digivice is random, any completed True Digivice can be recrafted into another version.
