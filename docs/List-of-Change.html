List of Changes

Battle Gameplay​

  • Advanced Skill-Breaking (ASB) has been removed.
  • Digimon are now divided into three roles:
    • ⚔️ Skill-based
    • 🗡️ Auto Attack-based
    • 🛡️ Tank
  • Added the new Skill Damage % stat to improve Skill-based Digimon.
  • Added a Tank Aggro System where enemies prioritize Tank-type Digimon.

Gameplay​

  • Increased drop rates for selected DigiEggs.
  • Mercenary Egg monsters now have a chance to drop Lv.4 Reinforced Eggs.
  • Data Egg Scans can now yield up to 3 Data per scan.
  • Increased Seal drop rate and quantity.
  • Added new custom accessories and equipment.
  • Improved Questline completion rewards.
  • Increased movement speed.
  • Increased Bit drops.
  • Added the Guild Skill System.
  • Verdandi monsters (except certain Raids) can drop X-Tickets.
  • Added Verdandi Daily Quests that reward X-Tickets.
  • Added Daily Quests for collecting Bokomon Book Pages.
  • Hard Mode Reward Boxes (EDG/ZDG/BDG/QDG) have been reworked:
    • Crystal items no longer drop from reward boxes.
    • Final dungeon bosses now have a chance to drop their respective Crystal.
    • Added a Crystal pity system.
  • Reworked Fanglongmon Dungeon difficulty.
  • Rebalanced Fanglongmon accessories.
  • Adjusted Royal Base (Normal Mode).

Digimon & Classifications​

  • Starter Digimon size can now be increased.
  • Starter Digimon (Agumon, Lalamon, Gaomon, Falcomon):
    • Hatch Level 5 by default.
    • Can use the Transcendence System after reaching 125% size.
  • Rebalanced Digimon ranks and stats.
  • Almost every Burst Mode is now S+ Rank.
  • Added Black Gear Evolution.
  • Digimon meta differs significantly from official DMO.
  • Added recolored Digimon variants.
  • Added custom Digimon (e.g. Sukamon).
  • Added Quick Evolution for multiple Digimon.
  • Added individual Attribute-based Jogress animations.

World​

  • Added custom Events, Raids, and Quests.
  • Increased monster spawn rates in selected maps.
  • Greatly increased Verdandi Yin & Yang Piece drop rates.
  • Added a new starting map and tutorial questline.
  • Server Continent monsters can drop Random BM Boxes.
  • Verdandi and Odaiba monsters can drop Tamer Exchange Tickets.
  • Added 12-player Guild Dungeon (IMD 2.0).
  • Added 8-player Guild Dungeon (Green Zone Nightsky).
  • Added new end-game dungeons.

Cash Shop​

  • Many Digimon previously locked behind Cash Promotions are now obtainable through permanent content or event loot boxes.
  • Added a pity system for loot box-exclusive SSS and SSS+ Digimon.
  • Some Digimon are permanently available in the Cash Shop, including:
    • Ophanimon Falldown Mode
    • Sleipmon X
    • Beelzemon X
    • Plesiomon
    • Aegismon
    • Examon
    • Mastemon
    • and more.

Quality of Life​

  • Added Maze navigation NPCs.
  • Increased Maze Quest Item drop rates.
  • Removed loading screens when moving within maps.
  • Can use up to 10 Monster Cards simultaneously.
  • Removed Accessory Enchantment animations.
  • Removed DigiClone animations.
  • Added customizable skill cooldown display.
  • Increased server tick rate.
  • Increased maximum camera distance.
  • Added Magnetic ID Card filters.
  • Added Clean UI toggle.
  • Added Movement toggle.
  • Adjusted Rainbow Bridge Truck location.
  • Added an exchange that grants all 10 Shining Spirits for KaiserGreymon and MagnaGarurumon.

Tutorial​

  • DMW Village replaces Old Yokohama as the starting area.
    • Accessible via the Cellphone NPC near DATS Center.
  • Added City of Beginnings as a beginner-friendly map.
    • Accessible through the portal behind Birdramon in DMW Village.
  • Added permanent beginner equipment.
  • Added a beginner dungeon (Gizumon Dungeon) to teach dungeon mechanics.

Others​

  • Master Membership is tradable.
  • Added scalable inventory.
  • Added performance settings to reduce Raid lag.
  • Added Dark Mode UI.
  • Added Lottery System.
  • Removed fog effects from selected maps and dungeons.
