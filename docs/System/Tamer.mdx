## Active and Passive Skill

![An image from the static](/img/tamers/tamer.png)

- Each tamer have 2 slot active skill and 3 passive skill
- You can change tamer whenever you already unlock that
- you can use tamer model and keep other passive tamer
- Deleted Tamer Skill can be restored if duration still available
- Single cooldown time will be applied for both skills when same type of Tamer Skill and Enhanced Tamer Skill are registere simultaneously.
- You can register 2 Enhanced Tamer Skills by maximum, and register them individually.
- Enhanced and Ultimate Tamer Skills are removable, and free to switch anytime.
